# Support & Getting Help

Welcome to Climate Commons! Here is how to find help or report issues:

## Getting Help

- **Questions about an existing workflow:** Open a GitHub Discussion or create an issue describing the specific workflow and context.
- **Workflow Ingestion Assistance:** Use the **Workflow Ingestion** issue template to have institutional automation assist in onboarding scripts.
- **Bug Reports & Broken Workflows:** Open a GitHub Issue using the standard issue template, providing error logs, system details (e.g. MareNostrum 5 module versions), and reproduction steps.
- **Documentation Drift or Inaccuracies:** Open a PR or submit an issue referencing the affected documentation page.

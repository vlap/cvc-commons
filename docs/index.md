# Climate Commons PoC

**A living documentation system for BSC climate computing.**

## Workflows
See [WORKFLOWS.md](WORKFLOWS.md) for the full list of verified workflows.

## How to Contribute
1. Drop your scripts in `/workflows/<your_workflow>/scripts/`.
2. Add a `metadata.yaml` (see template).
3. The **Intake Agent** will generate docs for you.

## Archive
Legacy workflows are archived in `/workflows/legacy/`.
